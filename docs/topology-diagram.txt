 WHY THERE ARE NO ROUTED LINKS
   In a Router-on-a-Stick design the router owns every subnet on 802.1Q
   subinterfaces of ONE physical port. No link in this topology is a
   Layer-3 point-to-point segment, so no /30 transit networks exist and
   no routing protocol is required. Every packet between two departments
   travels UP the trunk to R1-CORE and back DOWN the trunk. This is the
   classic "router-on-a-stick hairpin" and is the trade-off accepted in
   exchange for needing only one router interface.

-------------------------------------------------------------------------
 CABLE TYPE RULE USED
-------------------------------------------------------------------------
   Router  <-> Switch : STRAIGHT-THROUGH  (unlike devices)
   Switch  <-> Switch : CROSS-OVER        (like devices)
   PC/Srv  <-> Switch : STRAIGHT-THROUGH  (unlike devices)

   Packet Tracer 8.2+ 2960 switches do support Auto-MDIX, so a
   straight-through cable between two switches will usually still come
   up. The crossover cable is used anyway because it is the answer
   expected in an exam and it removes all ambiguity.
